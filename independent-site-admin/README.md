# 独立站管理后台交互原型

[在线打开](https://snowkiss233.github.io/points-mall/independent-site-admin/)

纯 HTML/CSS/JavaScript，包含完整后台菜单与二级管理页面。支持商品、供货商、批次库存、渠道、实名配置、订单查询、退款查看、内容推荐和权限字典的本地演示。

直接打开 index.html 即可使用。所有记录均为虚构演示数据；修改仅保存在当前浏览器，不连接真实后台、不执行实际支付或实名认证。

部分原后台空列表无法确认行操作；相关页面标注了演示边界。Excel 导入在此使用 CSV/TXT/粘贴模拟，真实第三方集成未接入。

视觉参考 NN 积分商城原型，发布复用 points-mall 仓库已有的 GitHub Pages 工作流。

| 验收项 | 操作与预期 |
|---|---|
| 发售状态配置 | 商品管理编辑发售状态，保存后检查列表、筛选及再次编辑的回显。 |
| 发售时间 | 商品新增／编辑选择未发售时，可选填年月日，后台回显及客户端均展示如「2026年09月24日」；留空即时间待定，无复选框。已发售时隐藏该项，保留已有时间资料；到达日期不自动更改发售状态。 |
| 授权登录 | 数据字典 → 授权登录开关 → 字典配置，分别编辑 NN、雷神的是否启用，保存后检查回显与相互独立性。 |
| 推荐专区 | 推荐管理通过“栏目类型”选择栏目；点击栏目列表，以弹窗查看枚举，无查询区域及标识列；编辑排序/启停后列表实时更新，关闭弹窗回到原推荐列表。 |
| 标签类型与游戏标签 | 标签类型由数据字典维护，初始为游戏类型、游戏模式；游戏列表和新增／编辑表单统一使用“游戏标签”，新增标签类型无需改页面字段。存量标签均归游戏类型，同类型名称唯一，不同类型允许同名。 |
| 搜索底纹配置 | 权限管理 → 数据字典 → 搜索底纹 → 字典配置，维护 value（底纹文案）、key（唯一标识）、排序值、是否启用；单条固定，多条按排序每 3 秒循环。 |
| 激活指南 | 游戏类别新增／编辑增加文本字段；选择 Steam 时向空白字段预填，保留运营修改内容。正式文本待运营提供，当前为标注清楚的演示占位。 |
| 飞码配置 | 数据字典 → 飞码城市一致性（演示） → 字典配置，编辑是否启用，保存后检查回显。 |
| 角标标签 | 数据字典 → 角标标签 → 字典配置，维护角标选项；商品管理的新增、编辑表单可非必填单选，保存后再次编辑回显。 |
