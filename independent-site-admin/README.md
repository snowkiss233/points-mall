# 独立站管理后台交互原型

[在线打开](https://snowkiss233.github.io/points-mall/independent-site-admin/)

纯 HTML/CSS/JavaScript，27 个菜单页面和 8 个二级页面。支持商品、供货商、批次库存、渠道、实名配置、订单查询、退款查看、内容推荐和权限字典的本地演示。

直接打开 index.html 即可使用。右上角“原型数据”提供 JSON 备份、导入和恢复功能。所有记录均为虚构演示数据；修改仅保存在当前浏览器，不连接真实后台、不执行实际支付或实名认证。

部分原后台空列表无法确认行操作；相关页面标注了演示边界。Excel 导入在此使用 CSV/TXT/粘贴模拟，真实第三方集成未接入。

视觉参考 NN 积分商城原型，发布复用 points-mall 仓库已有的 GitHub Pages 工作流。

| 验收项 | 操作与预期 |
|---|---|
| 未发售展示 | 游戏类别找到“星海远征（一期演示）” → 展示预览，显示禁用的“敬请期待”；改为已发售后重新预览。 |
| 站点路由 | 游戏编辑分别选择仅大陆、仅香港、两站均选，保存后再次打开核对；展示预览切换站点并点击“模拟点击游戏信息”，核对购买路由；空选不能保存。 |
| 推荐专区 | 推荐管理 → 栏目列表查看新增枚举；编辑排序/启停，再新增推荐、选品、保存并打开专区预览。 |
| 游戏模式 | 标签管理按游戏模式筛选；新建模式并在游戏资料选择；存量标签均为游戏类型，同名的类型/模式独立保存。 |
| 飞码配置 | 数据字典 → 飞码城市一致性（演示） → 字典配置，编辑是否启用，然后通过规则试算验证停用、同城、异城、城市缺失。 |

新增 7 个推荐专区、单人/多人/在线模式为候选演示值。飞码试算使用虚构 IP 与手动选取的城市，不执行真实定位、拦截或停发；正式处置动作尚未确定。购买跳转仅在预览内切换，不访问真实商城或创建订单。
