# 独立站管理后台交互原型

[在线打开](https://snowkiss233.github.io/points-mall/independent-site-admin/)

纯 HTML/CSS/JavaScript，27 个菜单页面和 8 个二级页面。支持商品、供货商、批次库存、渠道、实名配置、订单查询、退款查看、内容推荐和权限字典的本地演示。

直接打开 index.html 即可使用。所有记录均为虚构演示数据；修改仅保存在当前浏览器，不连接真实后台、不执行实际支付或实名认证。

部分原后台空列表无法确认行操作；相关页面标注了演示边界。Excel 导入在此使用 CSV/TXT/粘贴模拟，真实第三方集成未接入。

视觉参考 NN 积分商城原型，发布复用 points-mall 仓库已有的 GitHub Pages 工作流。

新增 7 个推荐专区、单人/多人/在线模式为候选演示值。飞码试算使用虚构 IP 与手动选取的城市，不执行真实定位、拦截或停发；正式处置动作尚未确定。后台维护发售状态；前台购买行为按需求规则实现，本原型不提供购买预览。
授权账号按来源平台及 UID MD5 识别；MD5 不是登录凭据。手机号场景全部为虚构样例，先模拟验证再查询两个平台；查询失败不自动注册，多个历史账号不自动合并。平台开关关闭后历史账号保留，手机号登录仍可复用。真实服务接入、身份校验及离岸数据合规评估不属于本静态原型的完成证明。
