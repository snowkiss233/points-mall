# 独立站管理后台交互原型

[在线打开](https://snowkiss233.github.io/points-mall/independent-site-admin/)

纯 HTML/CSS/JavaScript，包含完整后台菜单与二级管理页面。支持商品、供货商、批次库存、渠道、实名配置、订单查询、退款查看、内容推荐和权限字典的本地演示。

直接打开 index.html 即可使用。所有记录均为虚构演示数据；修改仅保存在当前浏览器，不连接真实后台、不执行实际支付或实名认证。

部分原后台空列表无法确认行操作；相关页面标注了演示边界。优惠券指定人群支持实际读取 .xlsx 文件；其他历史导入流程使用 CSV/TXT/粘贴模拟。真实第三方集成未接入。

视觉参考 NN 积分商城原型，发布复用 points-mall 仓库已有的 GitHub Pages 工作流。

新建发放计划选择「全部用户 / 指定人群」，配置「立即发放」；定时发放保留置灰选项。「指定人群」下载空白 Excel 模板，仅填写 UID 列，上传 .xlsx 后去重并校验，原型单次最多 10,000 行、5 MB。格式错误、未知 UID、公式或精度丢失数据会阻止创建，修正后重新上传；名单保存在计划中。文件仅在浏览器本地读取，未接入真实用户服务。

新建计划只保留「取消 / 创建」，创建后立即生效。一期人工发放给所选人群每人发一张，执行完成自动结束归档；接口发放创建后接收活动请求，按所选人群校验资格，不自动给全员发券。人工发放的全部用户按创建时名单确定；接口发放的全部用户包含后来注册的有效用户。

模板列表将优惠券名称和优惠券 ID 拆列；点击「关联发放计划数」跳转至对应模板的发放计划列表，按模板 ID 精确筛选，刷新保留筛选，重置查看全部。发放列表将计划名称、计划 ID、发放方式、发放人群独立展示。

券有效期在计划内支持「固定日期 / 领取后有效」；后者从券实际到账时间起算 N 天（一天为24小时）。每张券记录实际起止时间，重复请求或退款返券不延长效期；计划结束不影响未过期的已领券。接口发放必须由三方返回活动名称、来源系统、UID、唯一奖励明细编号。

新计划创建即开启，不支持暂停、复制或结束后重启；保留历史未开启计划供继续处理，升级不自动发券。发放详情只读，无发放执行记录、计划操作记录及逐券操作。明细展示 UID、昵称、获券来源、领取时间、有效期、券使用状态、最近核销时间和券编号，支持查询及分页。「获券来源」展示「后台发放 + 操作人」或「活动奖励 + 三方返回的活动名称」。
